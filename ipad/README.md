# SIM Training для iPad — рабочее место инструктора

Отдельное нативное приложение SwiftUI, минимальная версия iPadOS 17. Использует существующий API SIM Training. Эта итерация предназначена для локальной проверки на симуляторе/устройстве; публикация в TestFlight пока не выполнялась.

## Запуск

1. Откройте `SIMTraining.xcodeproj` в Xcode.
2. Выберите схему **SIMTraining** и симулятор iPad, нажмите Run.
3. Для физического iPad в Signing & Capabilities выберите свою Team. Идентификатор сборки сейчас `ru.gvedynamics.simtraining`: перед регистрацией приложения проверьте его доступность в своём аккаунте.
4. Сервер по умолчанию — `https://type-rating.survey-ebt.ru`. Войдите под своей учётной записью **инструктора SIM Training**. Ключ обмена ATCD приложению не нужен.
5. Нажмите «Загрузить задания» и дождитесь завершения. Потом можно отключить сеть, открыть сессию и выставлять оценки.

В Debug-сборке доступен адрес локального сервера. На физическом iPad `127.0.0.1` указывает на сам iPad, поэтому для Django на Mac используйте адрес Mac в локальной сети, запуск Django на `0.0.0.0:8002` и добавление конкретного адреса Mac в локальный `ALLOWED_HOSTS`. HTTPS рабочего сервера менять для этого не требуется. В Release разрешён только рабочий HTTPS-сервер.

## Что реализовано

- Личный календарь инструктора, местные дата/время каждого тренажёра, отдельная отметка EXTRA.
- Загрузка заданий и предыдущих результатов назначенных пилотов для чтения без сети.
- Переключение между двумя пилотами одного назначенного экипажа.
- Общие оценки упражнений, оценки компетенций EBT, замечания и общие заметки.
- Сохранение черновика отдельным файлом после каждого изменения; восстановление после закрытия приложения.
- Обновление календаря не заменяет файлы черновиков.
- Отдельное подтверждение отправки итоговых оценок при наличии сети. Автоматической очереди отправки в этой версии нет.
- Проверка актуальности назначения перед отправкой: изменение задания, пилота, инструктора, времени или места блокирует передачу старого черновика.
- Если ответ на отправку потерян, черновик помечается как требующий проверки. «Проверить сохранение на сервере» сравнивает опубликованный результат с черновиком. Другой результат не перезаписывается.

Слушатель увидит результат через существующий сервер/веб-кабинет. Нативный кабинет слушателя, офлайн-ознакомление и PDF-библиотека — следующие этапы. Прямого обмена iPad↔iPad нет.

## Хранение

Токен входа хранится в Keychain с доступностью только на разблокированном устройстве. Пароль не сохраняется. Снимки заданий и черновики разделены по серверу и ID пользователя, находятся в закрытой папке приложения, на iPad используют полную защиту файлов и исключены из системного резервного копирования. Не удаляйте приложение до передачи нужных результатов: сервер не получает незавершённые локальные черновики. Выход из учётной записи не удаляет её файлы; после повторного входа они доступны тому же пользователю на том же устройстве.

Данные не передаются в ATCD напрямую. Новые назначения создаются в веб-системах/админке, затем загружаются в приложение. Опубликованные оценки сохраняются действующим серверным механизмом версий результатов.

## Проверка перед первым реальным использованием

На тестовом назначении загрузите задания, отключите сеть, заполните часть оценок, полностью закройте приложение и откройте его снова. Убедитесь, что черновик восстановлен, переключитесь на второго пилота и проверьте раздельность оценок. При сохранении одного пилота занятие экипажа остаётся запланированным до завершения второго. Верните сеть и отправьте результат одного пилота; сравните его с веб-кабинетом. Отдельно проверьте EXTRA и смену учётной записи.

В этой итерации готовится сборка без готовой иконки App Store и без выбранной Apple Team. Для TestFlight их нужно настроить после проверки приложения на iPad.

## Тесты и сборка

Из папки `ipad`:

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer swift test --scratch-path /tmp/sim-training-core-tests
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer xcodebuild -project SIMTraining.xcodeproj -scheme SIMTraining -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' -derivedDataPath /tmp/sim-training-ipad-build CODE_SIGNING_ALLOWED=YES CODE_SIGN_IDENTITY=- CODE_SIGNING_REQUIRED=NO build
```

У проекта нет внешних Swift-зависимостей. Команды не изменяют глобальный `xcode-select`, не устанавливают приложение на физический iPad и не публикуют его.
